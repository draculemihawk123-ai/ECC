# Service Connect Versioning Skill

Use this skill to keep feature implementation aligned with the product roadmap.

## Roadmap

- 0.1 Lead Assignment MVP
- 0.2 Credit & Lead Quality
- 0.3 Review, Trust & Provider Scoring
- 0.4 Notification & Automation
- 0.5 Manual Payment / Credit Package
- 0.6 Semi-Automated Matching
- 0.7 Provider Pro / Membership Packages
- 0.8 Customer Tracking & Advanced Review
- 1.0 Stable Marketplace
- 1.1+ Scale

## Version Decision Rules

### Version 0.1

Only implement the minimum flow:

- Auth roles.
- Customer request.
- Admin verification.
- Admin provider assignment.
- Provider unlock with credit.
- Max three providers per lead.

### Version 0.2

Improve lead quality and credit operations.

### Version 0.3

Add reviews and trust scoring.

### Version 0.4

Add notifications and scheduled automation.

### Version 0.5

Add manual payment and credit package operations.

### Version 0.6

Add matching suggestions while admin keeps control.

### Version 0.7

Add provider membership plans.

### Version 0.8

Improve customer tracking and review depth.

### Version 1.0

Stabilize operations, dashboards, metrics, monitoring, and governance.

### Version 1.1+

Scale architecture and channels.
